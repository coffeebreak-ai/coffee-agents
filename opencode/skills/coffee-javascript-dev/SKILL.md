# Coffee: JavaScript

Локальный `AGENTS.md`, `package.json` и уже принятые каталоги важнее. Чужой репозиторий как образец не открывай; структуру каталогов под другой язык не подгоняй.

Версию Node и целевые браузеры бери из проекта (`engines`, browserslist, CI), молча не поднимай. `const` по умолчанию, `let` только при переприсваивании, `var` запрещён. Новый код — ESM; CommonJS не переводи без задачи и не смешивай `require` с `import` в одном модуле.

Асинхронность — только `async/await`. Promise не оставляй без обработки: `await`, возврат из `async`-функции или явный `.catch(...)`. `try/catch` — для ожидаемых ошибок; ошибку не глуши, оборачивай `new Error("действие", { cause: err })`. Бросай `Error`, не строки. Пустой `catch` запрещён.

`fetch` — с `AbortSignal.timeout(...)` или `AbortController`; проверяй `response.ok`, иначе `throw new Error(\`HTTP ${response.status}\`)`. Повторы — только для идемпотентных операций, с лимитом, задержкой и jitter. URL, таймауты и секреты — из окружения или настроек, не из кода.

Node: ввод-вывод — `node:fs/promises` и потоки; `readFileSync`, `execSync` в обработке запроса запрещены. CPU — `node:worker_threads`; массовые задачи ограничивай пулом, а не безлимитным `Promise.all`. `Promise.allSettled` — когда падение одной задачи не должно ронять остальные.

Данные: аргументы не мутируй; наружу отдавай копию, вложенные структуры — `structuredClone`. Деньги и объёмы — целые в минимальных единицах или decimal-библиотека, не арифметика над `number`. Соединения и клиенты создавай один раз, не на каждый вызов.

## Проверка

Линтер, форматтер и тесты — те, что уже настроены (`npm run lint`, `npm test`); без скриптов — `npx eslint .`. Замечания правь в коде, конфиг — только по прямой просьбе. Зависимости и lock-файл не меняй без прямой просьбы. Комментарии и JSDoc — только по прямой просьбе.
