# Coffee: внешние вызовы

На вызов наружу — таймаут, повтор с backoff и jitter, ограничение частоты. Вход проверь на границе сервиса.

Повторяй только 5xx, 429, таймаут и обрыв соединения. Остальные 4xx не повторяй. Вызов без ключа идемпотентности не повторяй.

Поле и правило ключа — навык `coffee-contract-first`.

Тело ответа вычитывай и закрывай: `defer resp.Body.Close()` и `io.Copy(io.Discard, resp.Body)` перед закрытием, иначе keep-alive соединение не вернётся в пул.

Метрики и спаны добавляй только если клиент уже есть в проекте. Лог структурный, `trace_id` из `ctx`. Динамический id в имя метрики не пиши. Нет OTel или Prometheus — не подключай.
