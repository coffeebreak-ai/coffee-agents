# Coffee: Lua (emilua)

Код пишется под **emilua**, а не под стоковый `lua`/`luajit` и не под OpenResty. Версию emilua бери из проекта; `spawn`, `this_fiber` и `sleep` — глобальные или штатные модули рантайма, сторонние библиотеки не выдумывай.

Всё локальное: `local` для переменных и функций, глобалы не создавай. Модуль возвращает таблицу в конце, побочных эффектов при `require` нет. Вложенность держи плоской, ранний `return` вместо `else`. Версию Lua (5.4 или LuaJIT) не меняй без задачи; в LuaJIT помни, что все числа — double.

Конкурентность — файберы. `spawn(fn)` создаёт файбер, `join()` ждёт и перебрасывает его ошибку, `detach()` отпускает. Многозадачность кооперативная: переключение только в точках приостановки — I/O, sync-примитивы, `this_fiber.yield()`. Внутри одной VM файберы не идут параллельно, но состояние между точками приостановки разделяемое: не держи инвариант через `sleep` или `receive`.

Отмена — `fib:cancel()` (до 0.12 — `fib:interrupt()`). После отмены файбер остаётся отменённым, прерывание срабатывает только в interruption point. Дочерние файберы гаси в cleanup-хендлере: `scope()` и `scope_cleanup_push`, порядок — обратный регистрации. Хендлеры выполняются с отключёнными прерываниями; ошибка в хендлере завершает VM, поэтому очистка не бросает исключений.

Между VM — только сообщения. `spawn_vm(module|opts)` возвращает tx-channel; точка входа актора работает с `_CONTEXT='worker'` и получает `inbox`. Значения копируются глубоко; `mutex`, файберы и объекты I/O с незавершёнными операциями передавать нельзя. Каналы закрывай, иначе контекст не освободится; в цикле актора первым делом `scope_cleanup_push(function() inbox:close() end)`.

Ввод-вывод — только неблокирующий, модулями emilua (`filesystem`, `stream`, `tcp`, `unix`, `tls`, `sleep`, `time`). Файловый I/O доступен только в proactor-контексте. `os.execute`, `io.*`, `os.exit` и busy-wait в библиотечном коде запрещены. У каждого ожидания — таймаут или путь отмены; для таймаута поднимай watchdog-файбер и отменяй цель.

Ошибки: `error()` — для нарушений контракта и багов, `nil, err` — для ожидаемых отказов, `assert` — для предусловий. `pcall` — узко вокруг конкретного вызова, не вокруг всей программы; ошибку не глуши и добавляй контекст. Строки в цикле собирай через `table.concat`; общие таблицы не мутируй без копии; порядок `pairs` не считай стабильным.

Деньги — целое в минимальных единицах (в LuaJIT проверь предел 2^53) или строка; арифметика над float для денег запрещена. Секреты — из окружения, не из кода.

## Проверка

Команды линтера и тестов — те, что уже настроены (`make lint`, `luacheck`, `stylua --check`, `busted` или `emilua` для тестов). Конфиги не меняй без прямой просьбы. Комментарии — только по прямой просьбе.
