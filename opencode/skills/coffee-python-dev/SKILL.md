# Coffee: разработка на Python

Python 3.11+, целевой 3.12. Пакеты — `uv`, проверка — `ruff` и `mypy`, тесты — `pytest`.

## Типизация

* Аннотации у всех аргументов, возвращаемых значений и полей классов.
* `Any` запрещён там, где структура описывается через `TypedDict`, `dataclass` или `BaseModel`.
* Настройки — `pydantic-settings`, не `os.environ` по коду.

## Pydantic v2

* Все границы валидируются моделью: тело запроса, ответ внешнего API, сообщение очереди, конфиг.
* Только API v2: `model_validate`, `model_dump`, `model_dump_json`, `field_validator`. Методы `parse_obj`, `.dict()`, `.json()` устарели.
* Наружу отдаётся `model_dump(mode="json")`; `Decimal` и даты сериализуются строкой.

## Синхронность

* **Асинхронности нет.** Запрещены `async def`, `await`, `asyncio` и async-драйверы: проект синхронный.
* Параллельные внешние вызовы — `concurrent.futures.ThreadPoolExecutor` с явным лимитом воркеров и таймаутом. Только для I/O, не для CPU.
* Соединения и пулы создаются один раз в фабрике приложения, а не на каждый запрос.

## Ошибки и логи

* Ловить конкретные исключения. `except:` и `except Exception: pass` запрещены.
* Ошибка логируется с `logger.exception(...)` и структурным контекстом: ID сущности, ключ идемпотентности, внешний сервис.
* Деньги и точные расчёты — `decimal.Decimal`, не `float`.

## Внешние вызовы

* HTTP — синхронный `httpx.Client`, не `requests`. Таймаут задаётся всегда и явно.
* Повторы — `tenacity` с лимитом попыток, задержкой и jitter. Повторяются только идемпотентные операции.
* Ключ идемпотентности создаёт инициатор; получатель его не подменяет.
* Каждый вызов — таймаут, метрика и лог; проглоченный ответ внешнего сервиса запрещён.

## Стиль

* Секреты, URL и таймауты — только из настроек.
* Изменяемые значения по умолчанию запрещены (`def f(x=[])`); пути — `pathlib.Path`.
* Комментарии и docstring — только по прямой просьбе.

## Проверка

* `ruff check` и `mypy` обязательны; конфиги линтеров не править.
* Временный `test_*.py` для проверки гипотезы допустим, но до сдачи удаляется: в diff его быть не должно.
